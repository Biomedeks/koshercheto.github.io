## 🛠️ Инструкции за тестване на сайта (Локално развитие)

Тъй като проектът е частен, можете да го стартирате и тествате на вашия компютър по следния начин:

### 1. Клониране на проекта
Отворете вашия терминал и клонирайте хранилището:
```bash
git clone https://github.com[Вашето-Потребителско-Име]/[Име-на-Проекта].git
```

### 2. Стартиране в браузъра
*   **Вариант А:** Просто отворете основния файл `index.html` с двойно кликване във вашия уеб браузър (Chrome, Firefox, Safari).
*   **Вариант Б (Препоръчително за VS Code):** Използвайте разширението **Live Server**, за да стартирате локален сървър с автоматично обновяване на страницата при промени.

### 3. Проверка на защитния текст (Footer)
Уверете се, че най-отдолу на уеб страницата (във футъра) правилно се визуализира знака за авторско право:
